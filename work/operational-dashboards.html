Operational dashboards · German Experts, Abu Dhabi · 2024 to now

Giving workshop managers a live view of the day

Managers wanted to know how the workshop was doing today, not at the end of the month. I built the dashboards they use for that, one per role.

Problem
Workshop, service, call-centre and HR managers had no single, current view of the operation.
What I built
A technician performance dashboard with an embedded AI assistant, and KPI dashboards for service advisors, the call centre, leads and attendance.
Outcome
Managers see jobs, invoices and productivity as they happen, and can ask a question instead of waiting for a report.

Context

The group runs workshops, service advisors and a call centre across Abu Dhabi and Dubai. Each team looks at the same operation from a different angle.

The problem

  • Technician productivity only means something when it is measured against work that was actually invoiced.
  • Service advisors, the call centre and HR each needed their own view.
  • Attendance lived on biometric devices with no clean route into the rest of the data.

What I did

  • Built the technician performance dashboard: jobs, invoices and productivity in one view.
  • Embedded an AI assistant that answers managers' questions about jobs, invoices and technicians in plain language, from live data.
  • Built KPI dashboards for service advisors, the call centre, leads and attendance.
  • Wrote a Python FastAPI service that syncs the biometric attendance devices into SQL Server.

How I approached it

  • One dashboard per role. A service advisor and an HR manager need different screens, so they get different screens.
  • Logic next to the data. KPI calculations live in SQL Server stored procedures and functions, so every dashboard counts the same way.
  • Let people ask. The assistant covers the questions a chart can't answer at a glance.

How it fits together

Where it landed

  • Managers see workshop productivity live, measured against invoiced work.
  • Each team has a dashboard built around its own job.
  • Attendance data arrives from the devices without manual exports.

Built with SQL Server, T-SQL stored procedures and functions, C# / .NET, Python FastAPI, self-hosted LLM

Written at the level of what the system does. No company code, data, screenshots or internal details.
