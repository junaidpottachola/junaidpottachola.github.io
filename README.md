# Mohamed Junaid: Portfolio

Static personal portfolio site. Plain HTML + CSS + a small vanilla JS file, no build step and no frameworks.

```
portfolio/
├── index.html      # generated by tools/build_portfolio.py (edit the script, not the HTML)
├── styles.css      # design tokens, layout, light/dark themes (OS setting + toggle)
├── script.js       # theme toggle (remembered), copy email, active nav link
├── assets/
│   └── profile.jpg # square headshot, 600x600
├── cv/
│   └── Mohamed_Junaid_CV.pdf  # target of the "Download CV" buttons
└── _qa/            # QA screenshots + mobile-frame.html helper (do not need to be published)
```

## Preview locally

Double-click `index.html`, or serve the folder:

```bash
python -m http.server 8000   # then open http://localhost:8000
```

## Before publishing

1. Copy the final CV to `cv/Mohamed_Junaid_CV.pdf`.
2. (Optional) Add a professional photo at `assets/profile.jpg`.
3. In `index.html`, replace every `junaidpottachola` (canonical and Open Graph tags) with your GitHub username.
4. Read the whole page once more: nothing confidential (no customer names, server addresses, internal screenshots).

## Publish on GitHub Pages (user site)

1. Sign in to GitHub and create a **public** repository named exactly `<username>.github.io`
   (for example, if your username is `jdoe`, the repo is `jdoe.github.io`).
2. Upload the **contents** of this `portfolio/` folder to the root of that repo
   (`index.html` must be at the top level, not inside a sub-folder).
   - Web: *Add file → Upload files*, drag everything in, commit.
   - Or with Git:
     ```bash
     cd portfolio
     git init
     git add .
     git commit -m "Initial portfolio"
     git branch -M main
     git remote add origin https://github.com/<username>/<username>.github.io.git
     git push -u origin main
     ```
3. In the repo go to **Settings → Pages**, set *Source* to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at `https://<username>.github.io/`.
5. Add that URL to your LinkedIn profile (Contact info → Website) and to your GitHub profile.

## Updating

Edit `index.html`, commit and push; GitHub Pages redeploys automatically.

## v3 structure (case studies)

```
index.html                         # home: hero, highlights, 4 case-study cards, experience, skills, credentials, contact
work/ai-solutions.html             # case studies share ../styles.css and ../script.js
work/operational-dashboards.html
work/technician-app-apis.html
work/contract-warranty-platform.html
assets/og-image.png                # 1200x630 social preview (source: _qa/og/og-template.html)
sitemap.xml, robots.txt
```

All five HTML pages are generated by `tools/build_portfolio.py` so the header, icon sprite and footer stay identical.
The output is plain static HTML; the script is only an editing aid.

**Before publishing, set the contact email and regenerate** (the script does not store the address):

```powershell
$env:PORTFOLIO_EMAIL = "<your address>"; python tools/build_portfolio.py
```

Without `PORTFOLIO_EMAIL` the pages contain the placeholder `__EMAIL__`.

Regenerate the OG image after changing `_qa/og/og-template.html`:

```
msedge --headless=new --hide-scrollbars --window-size=1200,630 --screenshot="assets\og-image.png" "_qa/og/og-template.html"
```

If you edit pages by hand instead: when the nav or footer changes, update all 5 HTML files.
